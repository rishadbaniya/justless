# Changelog

Notable changes to Justless, newest release first, in the style of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 0.1.0 (unreleased)

### Command output

- `justless run -- COMMAND` keeps the exit status, shows a bounded preview and archives both streams; `log` replays any line range byte for byte.
- `search RUN TEXT` finds text in one run and `history TEXT` in every run, failures first, and both count the matches they leave out; `search` also hoists shared path prefixes, centers long-line windows, and collapses repeated intra-file matches.
- Structured polyglot test compactors (`cargo_tests`, `js_tests`, `polyglot_tests`, `rspec`, `phpunit`) group failures by normalized root cause (masking ephemeral tempdirs, hex addresses, UUIDs, timestamps, and durations), fold parametrized test families and empty Cargo workspace targets, group pre-test compiler warnings, report rerun diffs, and link every failure to its exact `[stdout:A-B]` / `[stderr:A-B]` lines across `cargo test`, `cargo nextest`, Jest, Vitest, Bun, Playwright, `node --test`, `pytest`, Python `unittest`, `go test` (including races and panics), RSpec, PHPUnit/ParaTest/Pest, `dotnet test`, Maven Surefire/Failsafe, Gradle, Swift (`XCTest` and Swift Testing), CTest, Elixir `mix test`, `deno test`, and Flutter/Dart (`flutter test`, `dart test`).
- `cargo test` reports its totals with one line per test binary, also after `2>&1`, and a clean `cargo build` or `clippy` is one line: this repository's 58.7 KB test run shows as 0.7 KB, and `fixtures/failing` compacts from 18,038 B (380 lines) to 517 B (9 lines).
- Compiler and linter findings are grouped by rule with counts and up to four locations across 28+ tools: rustc, Clippy, `cargo doc`, Ruff, flake8, pylint, mypy, Pyright, Ty, ESLint, Biome, Oxlint, `tsc`, ShellCheck, golangci-lint, `go vet`, `staticcheck`, RuboCop, SwiftLint, Hadolint, gcc, clang, swiftc, MSBuild, Maven, Gradle, Flutter/Dart (`flutter analyze`, `dart analyze`), plus 12 ecosystem linters (`phpstan`, `clang-tidy`, `cppcheck`, `yamllint`, `markdownlint`/`markdownlint-cli2`, `sqlfluff`, `ktlint`, `stylelint`, `deno lint`/`check`, `ansible-lint`, `actionlint`, and `credo`), with clean-build summaries.
- BuildKit and container build step compactor (`buildkit`) collapses Docker, Docker Compose, and Podman BuildKit progress and cached layers while preserving fatal error details (`18.4 KB → 498 B`).
- Universal lossless CLI table compactor (`tableview`) handles ASCII grids, `psql` aligned tables, Unicode box/aligned tables, DuckDB typed tables, and standalone Markdown pipe tables (including escaped pipes) with bijective Tier 1 encoding (hoisting constant and ≥70% majority-default columns) and bounded Tier 2 previews carrying `[stdout:A-B]` elision ranges (`27.5 KB → 4.0 KB`).
- Universal RFC 4180 CSV/TSV compactor (`csvview`, wired into `run` and `exec`) provides bijective Tier 1 encoding with UTF-8 BOM handling, constant/majority hoisting, and round-trip verification, plus Tier 2 schema/type/range/cardinality summaries with head/tail samples and `[stdout:A-B]` elision ranges (`115.4 KB → 1.7 KB`, 98.5% saved).
- Dependency tree and graph deduplicator (`deptree`) compacts `cargo tree` (forward, `-i`, `-d`), `npm ls`, `pnpm list`/`ls`, `yarn list`, `pipdeptree`, `go mod graph`, `mvn dependency:tree`, `gradle dependencies`, and `dart pub deps` / `flutter pub deps`, highlighting errors and multi-version duplicate packages with exact archive pointers (`15.7 KB → 1.5 KB`).
- Searches are grouped by file and listings by directory, with uniform `ls -l` metadata hoisting, ISO timestamp handling, single-child path collapsing, extension breakdowns for dense directories, and context-block search grouping (`rg -n "fn " src`: `357,380 B → 4,058 B`, `88×`).
- Tiered semantic diffs (`summary`, `lockdiff`) summarize `git diff`, `git show`, `git log -p`, `gh pr diff`, `glab mr diff`, and merge commits by commit and hunk, folding whitespace-only hunks, pure renames, generated/snapshot files (including `.g.dart`, `.freezed.dart`, `.terraform.lock.hcl`), and large SVGs, and summarizing **18 polyglot lockfiles** (`Cargo.lock`, `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `bun.lock`, `uv.lock`, `go.sum`, `poetry.lock`, `Gemfile.lock`, `composer.lock`, `flake.lock`, `Package.resolved`, `mix.lock`, `pubspec.lock` [91.8% saved], `gradle.lockfile`, `Podfile.lock`, `packages.lock.json`, and `Pipfile.lock` [96.8% saved]) with checksum/source-substitution supply-chain flags.
- Enriched Terraform, OpenTofu, Terragrunt (`terragrunt plan`, `terragrunt run-all plan`), and Pulumi plan summaries fold refreshes while surfacing `# forces replacement`, destroys, updates, and outputs (`14.6 KB → 1.3 KB`).
- Extended CLI, Cloud/K8s, DevOps, and Git views (`cli_views`, `cloud_views`, `inventory`, `gitview`): `kubectl diff` / `oc diff` (folding `managedFields`/`resourceVersion` metadata noise while keeping real spec/data changes verbatim), `helm template` / `helm get manifest` (per-resource inventory with Secret-value safety), `aws s3 ls` (prefix-grouped recursive listings), `gcloud … list` / `az … list` / `aws cloudformation describe-stack-events` (pinning failed/unhealthy/rollback rows at top), `kubectl get` & `kubectl describe`, Helm releases, Docker/Compose/images inventories, `gh pr checks`, `gh run view`, `gh pr view`/`issue view`/`pr list`, `glab mr view`/`ci`, security audits (`npm`/`pnpm`/`yarn`/`cargo`/`pip` audit), package lists, lossless `git blame`, and compact `git status`, `git log`, `git branch`, `git tag`, `git stash list`, and `git reflog`.
- Bijective deep-schema JSON compaction (`jsonview`) unpacks nested structures, hoists majority defaults, extracts sub-tables with outlier escapes, and verifies round-trip decoding (`gh api` 80 nested objects: `30.2 KB → 3.6 KB`).
- Opt-in `lossless_only = true` setting in `.justless.toml` restricts output replacement strictly to bijective/lossless views (`jsonview`, Tier 1 `tableview`/`csvview`, and `git blame`) while leaving lossy previews, logs, and truncation untouched.
- Prefix-aware, JSON-aware (Zap/Pino/K8s JSON burst dedup + plain klog), non-consecutive log template folding (`logview`, including on merged streams) and workspace-aware external stack-frame collapsing (`stacktrace`, including Rust and Dart/Flutter frames), wired into `run`, post-run compaction, and `exec` (`kubectl logs`: `45.9 KB → 1.1 KB`).
- Previews fold progress frames, timestamped repeats, long base64 and hex runs, and list failures first while keeping progress filters on overflow; reruns show what appeared, changed, or disappeared.
- Hooks route build, test, check, install, and display command forms (plus monorepo runners, `cargo +toolchain` families, Docker Compose, `git -C`/`--no-pager`/read-only global flags, and safe command/version-manager wrappers including `env`, `stdbuf`, `fvm`, `volta`, `fnm`, `pyenv`, and `pdm`), with build/install progress filters. Commands meant to change remote state or read secrets stay as written, and clients that auto-approve rewrites take only safe local commands.
- Hook-routed runs add a footer only when output was cut or the command failed: on 13 routine commands it adds 3.7% to the output instead of 29.1%.
- Preview budgets adapt to how often each command family's clipped output is replayed, persisting replaced streams and budget metadata while keeping the archive within `max_run_bytes`, `max_runs` and `max_archive_bytes`.
- Secrets such as cloud keys, tokens and private keys are masked in previews, logs, searches and MCP results (with sound pre-regex fast paths); `log --unredacted` returns the original.
- `justless exec` runs a script over large data with `run`'s archive, exit status, lossless `jsonview`/`tableview`/`csvview`, `logview`, and `stacktrace` folding; `--intent TEXT` ranks the output lines that match.
- `justless test --affected` runs only the tests the current changes reach across Cargo, cargo-nextest, pytest, Jest, Vitest, Bun, `node --test`, Playwright, Go, RSpec, Flutter/Dart (`flutter test` / `dart test`), and Deno (`deno test`), labeled as a subset, or the full suite with a reason; `test --compare REF` separates new failures from baseline ones, and `--base REF` reviews a branch in `test --affected`, `affected`, and `context`.

### Code navigation

- A local incremental index of symbols, calls and imports covers 26 code-graph languages (Rust, JavaScript, TypeScript and TSX, Python, Go, Java, Kotlin, Scala, Groovy, C, C++, Objective-C, C#, Swift, Dart, Ruby, PHP, Elixir, Julia, Lua, Zig, Bash, PowerShell, SQL, and HCL/Terraform — plus Vue/Svelte/Astro components and shebang scripts), refreshed on every query.
- String-interned binary `.justless/index.bin` cache and dense CSR `usize` graph algorithms deliver **14.2× faster** warm `query` (`251.0 ms → 17.7 ms`), **12.4× faster** warm `map` (`425.0 ms → 34.3 ms`), **13.0× faster** `map --explain` (`403.0 ms → 30.9 ms`), **10.5× smaller** on-disk cache (`20.6 MB index.json → 1.96 MiB index.bin`), and a stripped release binary (`89.0 MB → 84.4 MB` / `80.5 MiB`) with zero new crates (`Cargo.lock` frozen at 144 crates).
- Pure-Rust zero-subprocess linked Git worktree detection seeds warm `.justless/index.bin` caches read-only from the primary checkout (`share_worktree_index = true` in `.justless.toml`).
- `justless map --html [--out PATH] [--explain SYMBOL]` renders a self-contained, offline, zero-CDN, XSS-safe interactive HTML5 Canvas graph explorer (`31.7 KB` on `fixtures/mixed`, `138.5 KB` on Justless's 250 top hubs / 98 communities / 40 bridges).
- `justless review [--base REF]` builds a strictly budgeted blast-radius PR/branch review pack combining semantic diff folding, reverse blast-radius walking, hub and cross-community bridge detection, and per-symbol test coverage-gap detection with suggested `test --affected` commands (also exposed via MCP `review`).
- `map` ranks hub symbols by weighted PageRank centrality, consolidates communities and cross-community bridges, tightens budget density, fixes test-path classification, and adds architectural `map --explain SYMBOL` (CLI and MCP).
- `lookup QUESTION` ranks symbols, Markdown sections, and config blocks, adds natural-language cross-language graph traversal via `lookup --graph` (CLI and MCP), deduplicates overlapping chunks, trims shared indentation, stems `-ion`/`-or`/`-ery` suffixes, and supports `--logs` for recent run output.
- `query`, `path`, `find`, `context` and `code` answer definition, caller, test and dependency questions with file and line coordinates, grouping duplicate callers and deduplicating outgoing `(from :LINE)` edges, skipping stdlib inferred noise, and balancing `query` sections (`query` median `71.3×`, up to `153.9×` vs. Claude Code's 2,000-line Read).
- `find` groups same-file hits, hoists shared directory prefixes, collapses repeats, centers long-line windows, supports `--path` and `--glob`, and prints the command for the next page when clipped.
- `pack "TASK"` gathers definitions, links, source lines, changes and failures within a byte budget, boosts dependency-cone ranking, caches per-file reads, and records emitted excerpts in session `seen` state.
- `affected` lists what depends on a symbol, a file or the current changes hop by hop with reaching tests; `context --run RUN_ID` ties a failure to its code.
- In a session, `context` and `pack` re-read a symbol as only its changed lines (512 bytes instead of 2,039 for one changed line); `--fresh` shows it whole, and so does compaction, in every project the session read.

### Reads and edits

- `read FILE --outline` covers **48+ structured outline formats** — 26 code languages (including JS/TS/Ruby test blocks, SQL/Rust items, Vue/Svelte/Astro components, and `#!` scripts), Markdown (`h1`–`h6` without signature duplication plus frontmatter, code-fence, and table anchors: `docs/reference.md` `273,594 B → 1,598 B`, `171×`), zero-dependency Jupyter notebooks (`.ipynb`, stripping base64/HTML media while surfacing headings, code signatures, and execution errors with exact cell spans: `52.3 KB → 745 B`, `98.6%` saved), and 18 config/DevOps/proxy/IDL/markup formats (TOML, YAML including K8s manifests, GitHub Actions workflows, and OpenAPI/Swagger specs, JSON/JSONC including OpenAPI, root arrays, and minified JSON, Terraform/OpenTofu/Terragrunt HCL `*.tf`/`*.tofu`/`*.hcl`/`*.tfvars`, Nix `*.nix`, Makefile/Justfile, Dockerfile/Containerfile, Nginx/Caddy/HAProxy configs, INI/Conf/EditorConfig/Properties, CSS/SCSS/Less, Proto/GraphQL/Prisma IDL schemas, and XML/HTML/MSBuild) — with window import folding, slim polyglot signatures, long Rust `const`/`static` initializer folding, external `mod` run folding, and `read --match` alternation.
- Budgeted directory Tree-sitter code skeletons via `justless read DIR --outline` fairly represent every file inside a byte budget with `REV#N` expand anchors (for example, `justless read src/proxy --outline` compacts 7 files / `112.9 KB` / 3,114 lines down to `4.1 KB`, a `96.4%` cut; full unclipped skeleton `13.1 KB`, `88.4%` cut).
- Cached compiled Tree-sitter queries (`LazyLock`) speed up 40-file outline batches by `>100×` (`159 ms` vs `>15 s`) and 10-file TypeScript outlines by `32×`, while eliminating redundant archive reads in `history`.
- `expand` supports `#A..#B` range expansion, multi-selector and cross-file batch expansion, overlap coalescing, hoisted multi-file prefixes, and session repeat-read delta dedup across CLI and MCP, returning exact bytes.
- `justless rename <SYMBOL> <NEW_NAME> [--dry-run] [--file PATH] [--json]` performs deterministic workspace-wide AST-safe symbol renaming across Rust (`syn` + `proc_macro2`) and Tree-sitter languages — zero LSP daemon, zero closed-file blind spots, identifier/keyword/collision validation, atomic path-bound revision checks + `syntax_check` before writing a single byte, and automatic rollback on I/O error (CLI only; MCP stays strictly read-only).
- `edit` writes a symbol or line range only if the file still matches the revision the agent read; a stale or overlapping edit rejects the whole batch.
- `edit` rejects a batch that would leave a parsing file unparseable, with the parser's line and message; `--allow-parse-errors` writes it anyway. In a crate with `#![feature(…)]`, Rust errors other than unpaired delimiters are reported, not rejected.
- Claude Code's Read hook outlines whole-file and ranged Reads of more than 600 lines (`read_outline_lines`), and shell reads keep their lines up to `read_outline_lines` as well.
- A Read of a file in a nested checkout (such as a Git worktree under `.claude/worktrees/`, a submodule, or a nested repository) is outlined for that checkout so its rows expand there and `resume` lists it there.
- Shell reads of a wide file with `cat`, `sed -n`, `head`, `tail`, `awk` line ranges, or `git show REV:path` show an outline and a replay command; Claude Code read lists also support `cat -n`, literal `echo`/`printf`, `pwd`, `true`, `ls`, `wc`, `git status --short`, `git log`, `grep` (with context, recursion, multiple patterns, counts, file lists, and final `head`), leading plain-word variables, globs, and safe out-of-workspace files.
- In Claude Code, unrecognized commands past the preview budget get a clipped preview rather than waiting for the 9.6 KB compaction floor.
- Outlines list up to 20 lines of uncovered top-level code (keeping the full read if more), and Claude Code and Antigravity CLI post-edit hooks report when a native Edit or Write leaves a previously parsing file unparseable.

### Tool history and sessions

- `mask` retires older tool results in an outbound request to `[justless recall ID]` references and `recall` restores them verbatim; duplicate tool outputs and superseded file reads or command runs are retired early even inside the recent keep-window, with deterministic secret-safe semantic cues in retired stubs.
- Multi-provider live-zone prefix-cache-safe compaction via `justless proxy --compact-live` (or `JUSTLESS_PROXY_COMPACT_LIVE=1`) compacts oversized newest tool results across **Anthropic `/v1/messages`, OpenAI `/v1/chat/completions`, OpenAI `/v1/responses`, and Google Gemini `:generateContent` / `:streamGenerateContent`** by **82.7%–96.6%** with **0% prompt-cache invalidation**, anti-recursion recall guards, and exact `justless recall` restoration.
- Read-only SHA-256 prompt-cache **prefix-drift detection** tracks `system`, `tools`, and prior `message[i]` fingerprints per `(endpoint, model)` across Anthropic, OpenAI, and Gemini (distinguishing `changed`, `reordered`, and `truncated` without storing any prompt text or secrets) and surfaces drift summaries in `justless stats` and `proxy --verbose`.
- Opt-in `justless wrap claude` runs Claude Code through the local proxy that asks the API to clear old tool results; `justless proxy` serves Anthropic, OpenAI, and Gemini API clients.
- Claude Code and Codex hooks carry recent run IDs, outcomes and inspected file ranges across compaction within 1,800 bytes, and `resume` prints the same handoff with coalesced same-file ranges and `[source changed]` markers after edits.

### Agent setup

- `install.sh` builds Justless from source with Cargo (using `git` so SSH `url.insteadOf` rules work) and sets up every supported agent found on `PATH`; build-from-source Homebrew `Formula/justless.rb` (`brew install --HEAD Formula/justless.rb`) is also included.
- `justless init` supports **12 coding agents** — Claude Code, Codex, Antigravity (CLI & IDE, `agy`), Cursor, Gemini CLI, GitHub Copilot, OpenCode, Windsurf, Cline, Roo Code, Kiro CLI, and Kilo Code — with a compact 457-byte instruction block surfacing code-graph commands, safe idempotent reruns, `justless init --dry-run` (zero-write preview), and `justless init --mcp` (combining instructions/hooks + MCP config in one call).
- Antigravity CLI (`agy`) provides two-tier mixed-chain routing, native before/after-read outlining with ranged and repeat-read guards, post-invocation edit parse checks, zero-token savings banners, global hooks, transcript discovery, and MCP install.
- OpenCode v1 plugin compacts native `Read`, `Grep`, and `Glob` tool outputs alongside `Bash`, and automatically retires older, duplicate, and superseded tool results on outbound requests.
- Hooks route safe segments in mixed `&&`, `||`, and `;` chains (including variable expansions, non-steering `NAME=value` assignments, single-quoted commands, and final `2>&1`); clients that auto-approve rewrites (Codex, Cursor, Antigravity) restrict auto-approval to safe local tools and skip exec-hook flags such as `rg --pre` or `go vet -vettool`.
- Claude Code's hook keeps permission rules in force by judging the original command, leaves file-reading commands untouched when `Read`/`Edit`/`Write` deny or ask rules exist, and compacts large unrouted Bash, Grep, and Glob outputs post-run.
- Codex code-mode scripts split lines as lists, route file reads through `justless read`, and preserve `| head -n N` / `sed -n` / `cut` windows with truncation notices; clients without post-run hooks route unpiped JSON reads (`gh … --json`, `kubectl get -o json`).
- `justless init --global` adds opt-in user-level hooks for Claude Code, Codex, and Antigravity CLI that serve every project unless `global_hooks = false` is set.
- `exclude_commands` (matched by shell words), `JUSTLESS_DISABLE=1`, invalid-config fail-open handling, and `justless rewrite "COMMAND"` control and inspect hook behavior.
- `justless mcp` serves 18 read-only commands (`query`, `path`, `find`, `lookup`, `context`, `code`, `read`, `expand`, `pack`, `map`, `affected`, `review`, `log`, `search`, `history`, `recall`, `resume`, `stats`) over stdio in a slim 6.1 KB schema with paged `recall`, path normalization, parity flags, and session read/expand dedup (`rename` stays CLI-only); `mcp --install` configures 11 clients (Claude Code, Cursor, Gemini CLI, VS Code, Codex, Antigravity CLI, Windsurf, Cline, Roo Code, Kiro, and Kilo Code).
- `justless doctor` checks the binary, all 12 agent CLIs/rules/hooks, instructions, MCP entries, status line, and `.justless/` state, printing an exact fix for every problem.
- `justless init --remove` undoes setup and restores untouched files byte for byte (`--dry-run`, `--purge`, `--global`).
- `justless learn` scans Claude Code, Codex, and Antigravity CLI transcripts (including background task results) to turn repeated command mistakes into project rules via `--apply`, including prerequisite-step and toolchain-wrapper patterns for Flutter/Dart (`pub get`, `build_runner`, `fvm`), Terraform/OpenTofu/Terragrunt (`init`, `init -upgrade`, `workspace`), Helm (`dependency update`), `uv` (`uv sync`/wrapper), kubectl context, and Docker `buildx`/context.

### Reporting

- `stats` reports exact bytes kept out of context by day and command (net of later replays and outline follow-up reads), code-graph invocation counts and measured savings (`map`, `query`, `path`, `context`, `pack`, `review`), and proxy live-compaction and prefix-drift counts, using per-content-type ratios calibrated on Claude's tokenizer (code, JSON, prose, logs); `--sessions` adds Claude Code session token usage.
- `stats --all` aggregates every project on the machine from the local registry across Claude Code, Codex, Antigravity CLI, and proxy clearing, and `log`, `search`, `context --run`, and MCP `log` locate runs across projects.
- `justless statusline` displays session savings with net savings percentage `(XX%)` in Claude Code's status line; `init --statusline` configures it without replacing an existing status line.
- `discover` summarizes unrouted commands across **8 coding agents** (Claude Code, Codex, Antigravity CLI, Cursor, Gemini CLI, OpenCode, Cline, and Roo Code) with a streaming prefilter, reporting command labels and byte counts only (never command arguments or output), with `discover --plan` producing an actionable coverage breakdown.
- Reproducible offline **26-workload** compactor benchmark suite (`scripts/suite_benchmark.py`: `1,544.5 KB → 59.6 KB`, `96.1%` saved, `25.9×` compression) and dark/light SVG + animated GIF asset generator (`scripts/render_assets.py`).
