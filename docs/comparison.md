# How justless compares

Two other projects work on the same problem from different angles. Both are worth knowing.

- **[RTK](https://github.com/rtk-ai/rtk)** also rewrites an agent's shell commands through hooks and filters their output. Its README lists more than 100 supported commands and 18 coding tools, far more than justless covers. RTK also offers smart file reads, a savings dashboard, and `rtk recall` for the full output of failed or trimmed commands. A separate optional proxy compresses API traffic, including large tool results already in the conversation. justless covers fewer commands. It archives every run by default, including output it showed in full, and each grouped failure, lint rule, search file or diff hunk names its line range in the log. It also compares reruns and adds a code index, verified edits and handoffs across compaction. Both tools rewrite the same shell commands, so use one of them for command output in a given project.
- **[graphify](https://github.com/Graphify-Labs/graphify)** turns a folder into a knowledge graph that an agent can query instead of grepping. It parses code locally with Tree-sitter in about 40 languages. It can add docs, PDFs and images through a model pass, and video through local transcription. It writes an interactive HTML graph and a report, and offers `query`, `path` and `explain`. It updates the graph with `--update`, `graphify watch` or a Git hook. It does not process command output. justless indexes source in 26 languages and searches other text files literally with `find`. It does not read PDFs, images or video and has no graph viewer. Its `map`, `query`, `path` and `affected` refresh the index from the working tree on every call, with no separate update step, and each result names a file and line.
